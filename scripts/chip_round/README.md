# Cartridge round — working scripts and outputs of the agents (2026-11-11/12)

These are the calculation scripts the agents wrote in a scratch directory while producing docs/09–16, with the
outputs they printed. They are kept as a record of how the numbers in those documents were obtained. They are **not**
part of the model package, have no tests, and were not reviewed as code.

**They do not run as they stand.** Each was run against a *copy* of the repository in a session scratch directory, so
that no generated file landed in the repo; ten of them contain that absolute scratch path (search for
`scratchpad`). To re-run one, point its `sys.path` / copy path at a checkout with `pip install -e .` done, and expect
the first run to build the transport-table cache (about 1 min). Model runs used n = 2000, seed 20261111.

now, but still as an unreviewed working script.
