Control and synchronisation

Empower

Runs the pump and sample manager from an ordinary sample set, one line per sample.

Inject-start signal

A contact closure from the sample manager, read by a small USB input device.

Python layer

Times every later step from each injection, using a step table.

Devices

Valves, syringe pump, magnet, and the Gamry through its own worker process.

Watchdog

A late, early or unexpected injection, or any device error, sends the system to a safe state.

Fault latch

Runs after a fault are flagged invalid until a recovery cycle has flushed the trap and cup.

Status

Tested in simulation only. The real hardware drivers, including the Gamry one, are still stubs.

Empower does not need to be started from Python in the primary scheme; whether the Toolkit can start a sample set is unverified and only a fallback. The Gamry worker must run in Gamry's own 32-bit Python 3.7 and talks to the main program over a local connection. The rear-panel signal details of the sample manager are unverified and are a Stage 0 check.
